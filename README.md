# 🎬 Movie Database API

A Django REST Framework based Movie Database API with authentication, search, reviews, favorites, and IMDb bulk import support.

---

## 🚀 Features

- ✅ Movie CRUD API
- ✅ Genre Management
- ✅ Reviews & Ratings System
- ✅ Watchlist & Favorites
- ✅ JWT Authentication
- ✅ IMDb Bulk Import API
- ✅ Movie Search API
- ✅ Swagger API Documentation
- ✅ MySQL Database Integration

---

## 🛠 Tech Stack

- Python venv
- Django
- Django REST Framework
- MySQL
- JWT Authentication (SimpleJWT)
- DRF Spectacular (Swagger Docs)
